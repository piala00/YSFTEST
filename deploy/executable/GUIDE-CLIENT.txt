ERP OHADA — GUIDE DU POSTE CLIENT

Le programme est installé dans Program Files\ERP-OHADA\<Édition>.
Les données de la société sont conservées séparément dans ProgramData\ERP-OHADA\<Édition>.
Remplacer le programme ne doit pas effacer les données.

Navigateur : l'interface s'ouvre dans un navigateur. Le programme ouvre de lui-même
Microsoft Edge ou Google Chrome (en mode application) quand ils sont présents, pour que
l'interface fonctionne de la même manière sur Windows 10, Windows 11 et Windows Server.
Si, sur un Windows 10 peu à jour, les menus semblent ne pas réagir aux clics, c'est que
le navigateur par défaut est trop ancien : installez les mises à jour Windows (Microsoft
Edge récent) ou Google Chrome, puis relancez le logiciel.

Licence : Administration du poste > Licence. Sélectionnez le fichier .erplic
remis pour ce serveur. L’identité publique de vérification est intégrée
au programme : aucun fichier public à sélectionner.
Aucune copie manuelle dans les dossiers Windows n'est nécessaire.
Le coffre privé de l'éditeur ne doit jamais être remis au client.
Une référence d'installation ne remplace pas une licence signée pour la machine.

Conservez vos sauvegardes dans un emplacement séparé et vérifiez leur restauration
sur un poste d'essai. Une mise à jour ne remplace pas une sauvegarde.
Avant une opération d'administration qui demande un redémarrage, terminez les
saisies des utilisateurs et consultez les messages affichés par le logiciel.

Installation/réinstallation : sélectionner l’autorisation signée .erpinst remise pour ce
serveur et cette édition. Elle est distincte de la licence .erplic qui active l’exploitation.
La désinstallation conserve les données par défaut. Un nettoyage interactif présente
l’inventaire, vérifie une nouvelle sauvegarde hors des dossiers ERP et demande confirmation.
