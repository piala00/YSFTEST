Sauvegarder

Télécharge dans un fichier toutes les données : société, exercices, utilisateurs, profils et droits, tiers, articles, documents, stocks, règlements, plan comptable, écritures, journal des événements. Gardez ce fichier en lieu sûr : il contient des données confidentielles.

Restaurer

Toutes les données actuelles sont remplacées par celles du fichier. Si le fichier est refusé ou incohérent, rien n'est modifié. Faites d'abord une sauvegarde de l'état actuel.

Sauvegarde chiffrée (anti-vol)

Produit un fichier .erpcoffre chiffré et protégé par un mot de passe : transportable sur clé USB sans risque. Sans le mot de passe, le fichier est inexploitable (un vol ou une copie ne révèle rien). Notez bien le mot de passe : il est irrécupérable.

Restaurer une sauvegarde chiffrée

Restaure depuis un fichier .erpcoffre. Le mot de passe est exigé : sans lui, la restauration est impossible. Toutes les données actuelles sont remplacées ; en cas d'échec, rien n'est modifié.
