# Validation technique du paquet

- Les CSV sont relus en UTF-8 avec séparateur point-virgule ; le nombre de colonnes est constant.
- Les clés d’états sont uniques par état/système/référence.
- Les tranches IGS sont contiguës ; les tests couvrent 499999/500000 et 49999999/50000000 FCFA.
- Les quatre formules et la cellule nette de stock citées dans le registre d’anomalies ont été comparées aux cellules du classeur source.
- Des montants synthétiques non nuls pour AP et DY détectent les omissions dans les totaux du modèle ; ils ne valident pas un moteur légal.
- Le calcul arithmétique du taux général TVA avec CAC a été vérifié sur 100000 FCFA.
- Les articles13 et26/28 du texte signé ont été lus visuellement (PDF pages20 et25 ; imprimées17 et22).

Ces contrôles ne certifient ni la légalité de tout paramétrage fiscal, ni les candidats du plan, ni le schéma du portail DGI2026. Aucune déclaration n’a été transmise.
