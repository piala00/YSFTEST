# Compléter les preuves V12

Ce protocole est une méthode proposée pour compléter ce paquet, pas une fonction attribuée à Sage.

1. Identifier le produit, la version complète, l’édition, les options et le mode d’hébergement dans À propos et le contrat. Conserver la date de contrôle.
2. Utiliser un profil neuf sans personnalisation et un dossier de test. Ne modifier aucune donnée réelle.
3. Capturer les sept menus, puis ouvrir chaque sous-menu. Relever les séparateurs dans l’ordre. Distinguer sous-menu, dialogue, onglet, champ et action contextuelle.
4. Pour chaque ligne, affecter son rang dans son parent, son type et le chemin complet. Ne compléter edition que sur preuve. Enregistrer une référence de capture ou de document pour chaque fait.
5. Ouvrir les paramètres société et relever séparément leur arborescence interne. Ne pas simuler des sous-menus à partir d’onglets.
6. Relever les profils, les groupes et les niveaux de droits dans les deux applications. Comparer les libellés avec les lignes historiques ; conserver les différences.
7. Dans un dossier jetable autorisé, tester chaque niveau sur consultation, création, modification, suppression, impression, export et accès direct. Vérifier l’héritage du parent et les exceptions. Enregistrer le résultat réel sans supposer une matrice uniforme.
8. Contrôler les protections de prix, marge, remise, dépôt, souche, journal et bon à payer. Suspendre BAP-01 jusqu’à une preuve non ambiguë.
9. Tester l’espace de travail avec plusieurs fenêtres, une saisie non enregistrée, les raccourcis et la barre verticale.
10. Fermer chaque inconnue seulement avec une preuve datée. Conserver les inconnues restantes ; ne pas les remplacer par des valeurs probables.

## Critères avant import exhaustif

Chaque parent existe ; les rangs de frères sont uniques et ordonnés ; chaque séparateur possède son rang ; aucune ligne de version historique n’entre dans le jeu V12 ; chaque édition est explicite ; les sources restent consultables. Les traitements fiscaux français observés ne constituent pas des obligations camerounaises.
