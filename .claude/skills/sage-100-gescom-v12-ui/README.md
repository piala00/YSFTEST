# Skill Claude — Sage 100 Gestion Commerciale V12, interface utilisateur

Skill en français conçu pour **Claude Code / environnements acceptant les Skills Claude**.

## Contenu

- `SKILL.md` : consignes d'activation et méthode de réponse.
- `references/` : 12 fichiers de référence couvrant menus, rubriques, interfaces, éditions et audit.
- `examples/DEMANDES.md` : exemples de questions à poser à Claude.

## Installation dans Claude Code

**Projet :** copier le dossier `sage-100-gescom-v12-ui` dans :

```text
VOTRE_PROJET/.claude/skills/sage-100-gescom-v12-ui/
```

**Personnel (partagé entre projets) :** copier le dossier dans :

```text
~/.claude/skills/sage-100-gescom-v12-ui/
```

Vérifier que le fichier se trouve à la racine du dossier :

```text
.../sage-100-gescom-v12-ui/SKILL.md
```

**Claude dans une interface qui accepte l'import de Skills ZIP :** téléverser l'archive ZIP si cette fonctionnalité est disponible. Les options exactes dépendent de la version du produit.
