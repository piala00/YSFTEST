# 07 — Menus Fenêtre et Aide

## Fenêtre [DOC-V12 — S1 page 14]

Les commandes suivantes sont explicitement listées dans le découpage V12.10 :

| Commande | Fonction décrite |
|---|---|
| Réorganiser | Disposer les fenêtres ouvertes |
| Actualiser | Rafraîchir la liste / les données visibles |
| Personnaliser | Adapter l'interface, les menus et barres/outils selon la configuration |
| Personnaliser les écrans | Ajuster zones, affichages et aspects des écrans autorisés |
| Personnaliser la liste | Modifier les colonnes / la présentation d'une liste active |
| Ajustement automatique des colonnes | Ajuster automatiquement les largeurs |
| Préférences | Régler la présentation et le comportement local |
| Barre verticale | Afficher / masquer le panneau de raccourcis |
| Mode assistant | Activer le fonctionnement guidé des fonctions concernées |
| Mode personnalisé | Utiliser la configuration personnalisée |

### Fenêtre > Personnaliser

Le menu a historiquement servi à gérer la présentation des menus, barres d'outils et raccourcis [ERG-CLASSIQUE]. Une documentation Sage évoque un **onglet « Programmes externes »** et des profils/conditions de sécurité, pour des versions/gammes spécifiques : il ne faut pas le présumer présent et actif sur une V12 locale standard.

### Fenêtre > Personnaliser les écrans

Un exemple récent de la communauté Sage explique comment accéder à la personnalisation puis utiliser le menu contextuel dans l'en-tête d'un document commercial. Cela illustre le rôle du menu mais ne décrit pas tous les champs V12. Pour auditer une facture, noter séparément :

- zones visibles et masquées dans l'en-tête ;
- éléments disponibles dans l'éditeur de présentation ;
- effets globaux ou par poste/profil, s'ils sont documentés ;
- options de sauvegarde et de restauration de la présentation.

### Fenêtre > Personnaliser la liste

Documenter au minimum : colonnes visibles, colonnes masquées, ordre, largeur, alignement, tri, filtres, sauvegarde du paramétrage, périmètre utilisateur/ordinateur. Ce sont des **éléments à constater**, non des garanties communes à toutes les fenêtres.

## Aide `?` [ERG-CLASSIQUE]

La barre de menus traditionnelle affiche souvent un menu `?` consacré à l'aide du logiciel, l'assistance, les informations de version et parfois les services en ligne. Le **découpage fonctionnel V12.10 S1 ne le détaille pas**. Demander une capture du menu ouvert avant de produire une arborescence V12 définitive. Ne pas inventer une liste d'entrées.
