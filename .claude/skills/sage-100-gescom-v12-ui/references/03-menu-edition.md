# 03 — Menu Édition [ERG-CLASSIQUE]

**Attention :** la matrice Sage V12.10 S1 ne détaille pas le menu « Édition ». Les familles ci-dessous sont décrites dans l'ergonomie des générations classiques et doivent être confirmées sur une capture V12 avant de figer les libellés, ordre ou raccourcis.

## Familles de commandes historiquement présentes

- **Presse-papiers et sélection** : Annuler, Couper, Copier, Coller, Effacer, Sélectionner tout.
- **Fiches et enregistrements** : Ajouter, Voir/Modifier, Consulter, Supprimer, Dupliquer (selon contexte).
- **Déplacement** : Précédent, Suivant.
- **Recherche** : Rechercher, Atteindre.
- **Outils contextuels** : Inverseur, Calculette Sage, Journal de traitement (selon édition/contexte).

## Fiche d'audit nécessaire

Sur la V12 de l'utilisateur, ouvrir Édition dans : (1) fenêtre principale sans document, (2) liste clients, (3) fiche article, (4) facture ouverte ; noter pour chaque commande : libellé, position, état actif/grisé, raccourci indiqué, dépendance à la sélection, boîte de confirmation. Ne jamais supposer que les mêmes commandes sont disponibles dans tous les contextes.
