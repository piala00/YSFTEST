# Familles et parcours

| Famille | Entrée | Sortie à préciser | Référence |
|---|---|---|---|
| Appel depuis un champ | Préfixe, touche ou bouton selon contexte | Code retenu et libellé ; retour au parent | L01-L09 |
| Recherche intégrée à une liste | Texte ou critères | Liste filtrée | C06, C11, P901 |
| Recherche multicritères | Fonction, objet, condition, valeur et combinaison | Fenêtre de résultats | C01, C02 |
| Sélection simple d’état | Dates, comptes, documents et options propres à l’édition | Impression ou étape suivante | G…, P… |
| Format avancé | Lignes Fichier/Champ/Groupe/De/à/Opérateur | Ensemble sélectionné et format enregistré | C09 et variantes G… |
| Sélection de traitement | Documents ou objets éligibles | Liste à traiter, puis résultat métier | Préparation, livraison, facturation, réapprovisionnement, inventaire |
| Choix d’une ressource | Fichier, format sauvegardé, modèle | Chemin ou ressource compatible | C03, C04, C08 |
| Personnalisation | Colonnes ou tris | Préférences d’affichage | C05, C12 |

## Choix depuis une saisie

Le champ parent transmet son contexte. La liste d’appel peut être préfiltrée par le journal, le tiers, le dépôt ou le document : ce préfiltre est à vérifier par fenêtre. Dans le témoin, les comptes tiers proposés en journal dépendent de son type. Le retour doit identifier l’objet choisi sans confondre son code et son libellé. Les raccourcis attestés ne doivent pas être copiés sur des fenêtres d’autres produits.

## Sélection avant impression

H04 distingue trois chemins : modèle standard imposé ; standard ou personnalisé ; modèle personnalisé imposé. Le choix de données, celui du modèle et celui de l’imprimante sont des étapes différentes. La zone Traitement n’est pas systématique. Les formats développés ne sont pas universels ; M01 indique une exception pour Journal général. L’impression d’un compte client Gescom passe par Interrogation commerciale tiers puis choix du modèle.

## Sélection avant traitement

La fenêtre peut conduire à générer un document, ajuster un stock ou modifier des données. Prévoir dans la recette un jeu d’objets éligibles et non éligibles, les contrôles et les rejets. Dans une spécification ERP, nommer explicitement le moment où le traitement commence ; sélectionner une ligne n’est pas une validation comptable.
